# Non-Goals

This repository is not:

- a Tobi implementation;
- a parser implementation;
- a canonicalizer implementation;
- a diagnostic emulator;
- a private fixture mirror;
- a private golden corpus;
- a runtime or backend language claim;
- a certification program;
- a proof-of-truth layer;
- a consensus product;
- a future product disclosure channel.

This repository must not publish:

- validator source;
- validator binaries;
- private release logic;
- private implementation details;
- customer artifacts;
- private corpus data;
- invented expected outputs.

The purpose is narrower:

```text
public examples + public manifest + real-run expected-output discipline
```
