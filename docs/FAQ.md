# FAQ

## Is this the Tobi Validator source code?

No. This repository contains public examples and conformance metadata only.

## Does this repository include the validator binary?

No.

## Are expected outputs final?

Only if the manifest marks the case as `VERIFIED_WITH_TOBI` and includes exact real-run evidence.

## Can I fill expected output from documentation?

No. Use real Tobi Validator output only.

## Is `_h` proof of truth?

No. `_h` is a compatibility identity only.

## Does validator acceptance mean consensus?

No. Validator acceptance is not consensus.

## Can I add broader language examples?

Not in v0.1 unless they are public-safe, `.tsubasa`, and verified through real Tobi runs.
